Fullstack · Buque insignia

Gestor de Gastos

Control de gastos personales con presupuestos por categoría, gastos recurrentes automáticos e importación desde CSV. La seguridad es el corazón del proyecto: autenticación en dos pasos con TOTP, rotación de tokens de refresco, límite de intentos y bloqueo temporal.

Demuestra seguridad de nivel producción y una API REST documentada sobre PostgreSQL.

  • C# / .NET 10
  • ASP.NET Core
  • Vue 3
  • PostgreSQL
  • Docker
